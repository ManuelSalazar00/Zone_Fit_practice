# Zone Fit - Customer Management (Console Application)

Backend project built with **Spring Boot** as a console application,
implementing a CRUD system following professional development standards:

- Domain-Driven Design (DDD)
- Test-Driven Development (TDD)
- Clean Code principles
- SOLID principles
- Layered Architecture
- MySQL persistence

---

## Project Goal

To build a customer management console application while applying
professional software architecture practices that ensure:

- Clear separation of responsibilities
- Framework-independent domain layer
- High testability
- Future scalability to REST API or microservices
